# Scenario B — drama path

The case where the obvious answer is wrong. This is the scenario that sells the template, so
write it carefully:

1. What invites the wrong call — the pressure, the plausible shortcut, the reassuring document.
2. The facts in the documents that overturn it.
3. The expected verdict, and the rule number the engine applied to get there.

End with the line that makes the point: *a naive reviewer does X; the engine does Y.*
