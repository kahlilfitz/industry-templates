# Reference & Naming Permission Rules — Credential & Case Study Assembly

Illustrative operational summaries for grounding. Replace with the firm's controlled engagement-terms library, reference policy and legal-approved permission register. Engines cite these sections; constants mirror the section numbers.

## 1. Consent baseline
| Rule | Condition | Effect |
|---|---|---|
| 1.1 | Express written consent names the client, states the permitted use and is traceable to engagement terms, amendment or reference-register approval | Eligible only within that stated scope |
| 1.2 | Express prohibition in engagement terms, master services agreement, order form or amendment | REFUSE-TO-NAME, regardless of relationship history |
| 1.3 | No permission record, missing clause, silence, verbal assurance, or "client seems fine with it" | SILENCE IS NOT CONSENT; REFUSE-TO-NAME |

## 2. Consent scope
| Rule | Scope | Permitted use |
|---|---|---|
| 2.1 | `pitch_only` | Named use in a private pitch to the identified recipient only |
| 2.2 | `public_marketing` | Named website, credential library or public case-study copy |
| 2.3 | `press` | Press release or media statement; does not imply public marketing rights unless stated |
| 2.4 | `event_only` | Named use for the stated event/session only; does not carry into credential libraries |

## 3. Expiry and renewal
| Rule | Condition | Effect |
|---|---|---|
| 3.1 | Consent expiry date is before the requested use date | REFUSE-TO-NAME until renewed |
| 3.2 | Consent has no expiry but engagement terms require renewal before reuse | Escalate and refuse until renewal is recorded |

## 4. Logo rights are separate
| Rule | Condition | Effect |
|---|---|---|
| 4.1 | Name-use consent exists but logo-use consent is absent | Client name may follow its own verdict; logo use is refused |
| 4.2 | Logo consent exists but name-use is prohibited | Logo may not be used because the credential cannot name the client |

## 5. Named individual quotes and testimonials
| Rule | Condition | Effect |
|---|---|---|
| 5.1 | A named-person quote/testimonial has a separate written consent record for the person and organization | Eligible within that stated scope |
| 5.2 | No separate named-individual consent | Remove or anonymise quote; never infer consent from project participation |

## 6. Outcome figure clearance
| Rule | Condition | Clearance |
|---|---|---|
| 6.1 | Figure is verified in deliverable evidence, has source citation and is not restricted by terms | CLEARED |
| 6.2 | Figure is client-supplied internal estimate, anecdotal, draft, unverified or not in deliverable evidence | UNCLEARED |
| 6.3 | Figure is cleared for private proposal use but not public marketing | CLEARED only for that requested use; otherwise UNCLEARED |
| 6.4 | Cleared and uncleared figures must be structurally separated; uncleared figures never appear in publishable copy |

## 7. Aggregation and re-identification
| Rule | Condition | Effect |
|---|---|---|
| 7.1 | An anonymised descriptor combines three or more identifying signals such as sector, size/rank, geography, date, unique programme, platform, transaction or role | Treat as re-identifying; block descriptor |
| 7.2 | A descriptor names a rare market position, top rank or uniquely timed programme even without the client name | Treat as re-identifying when combined with another signal |
| 7.3 | Safe anonymisation removes client name, logo, named people, exact dates, rank/size claims and unique programme labels unless expressly cleared |

## 8. Govern default and escalation
| Rule | Condition | Effect |
|---|---|---|
| 8.1 | Naming status cannot be proven as permitted for the declared use | Default REFUSE-TO-NAME |
| 8.2 | Any conflict between partner recollection, BD request, reference register or terms | Terms and explicit restrictions govern; escalate conflict |
| 8.3 | Governance output is draft guidance only | Legal/reference owner approval is still required before publication |
