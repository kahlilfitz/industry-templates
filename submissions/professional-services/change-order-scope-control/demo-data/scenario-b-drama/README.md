# Scenario B - drama path

Death by a thousand cuts: Meridian Harbor's client sponsor asks for a series of "quick" additions after missing the SOW assumption that the client would provide one clean export. Each individual request is small enough for an engagement manager to absorb, but six out-of-scope items total $15,231.75 in current change-order value. Prior no-charge accommodations add $5,650.00, so cumulative margin erosion at risk reaches $20,881.75 and exceeds the $12,000.00 escalation threshold.

Two traps make the scenario commercially credible:

1. `REQ-B-007` looks like an added executive report, but the SOW's readiness-report clause broadly includes an executive summary dashboard. The engine classifies it IN_SCOPE and protects the client relationship.
2. `REQ-B-008` asks for a Legal approver exception path. The deliverable list includes Legal approver roles in the prototype, but the exclusion list excludes Legal/compliance workflow redesign. The engine marks it AMBIGUOUS and refuses to decide.

A naive reviewer says "just absorb it." The engines cite the failed assumption, quantify cumulative drift, preserve the in-scope item and route the contradictory item to human review.
