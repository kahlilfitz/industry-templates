# Audit Readiness - Cowork Plugin (Wave 2)
Knowledge Assistant + Govern (Connect -> Analyze -> Govern -> Create) - Govern is the core work, not a wrapper. Attended, draft-first.
Skills: scope-map -> evidence-gather -> gap-check (Govern) -> readiness-pack.
Contract: mfg.audit-readiness.v1. Engines: clause_map, gap_check (#1 recency, #2 coverage, #3 severity, #4 verdict, #5 no paper-over). Constants mirror references/audit-rules.md.
Demos: scenario-a-happy (surveillance audit, one stale calibration -> conditionally ready), scenario-b-drama ("we passed last year, folder is full" - management review minutes 13 months old, internal audit missing one scope area, new inspector without training record -> 3 MAJOR gaps, NOT READY).
Grounded in ISO 9001, IATF 16949, ISO 19011. Boundary: readiness pack; producing evidence is human work.
