# Support

## How to get help

Templates in this gallery are **example implementations provided as-is**. They are not a
supported Microsoft product and carry no service-level agreement.

- **Something wrong with a template?**
  [Open an issue](https://github.com/SravaniSeethi/industry-templates/issues/new?template=feedback.yml)
  and name the template.
- **Question about the gallery itself** — the site, the submission format, the importer? Same
  place.
- **Want to contribute or change a template?** See [CONTRIBUTING.md](CONTRIBUTING.md).

## Before you file

Include the template slug, what you expected, what happened, and — if it is a package problem —
which skill and which demo scenario you were running. The `demo-data/*/expected/` files are the
reference outputs, so a diff against those is the most useful thing you can attach.

## Platform questions

For Microsoft 365 Copilot Cowork, Copilot Studio or Scout itself — installation, tenant
configuration, licensing — use Microsoft's own support channels, not this repository.
